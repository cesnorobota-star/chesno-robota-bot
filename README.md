# Чесно Робота: автоматизація Threads

## Як це працює зараз (GitHub Actions)

- Розклад: `.github/workflows/autopost.yml` щогодини запускає цикл, який з 07:00 до 23:00 за Києвом кожні 3 хв виконує `autopost.py run`. Репозиторій публічний, тому хвилини GitHub Actions безкоштовні.
- Черга: `posts_queue.csv` у цьому репозиторії. Після кожної публікації бот сам комітить оновлений файл (статус, id поста).
- Токен Threads зберігається в секреті репозиторію `THREADS_ACCESS_TOKEN` (Settings → Secrets and variables → Actions).
- Щодня о 08:05 за Києвом бот перевіряє токен. Якщо токен недійсний, GitHub надішле лист про збій.
- Токен діє 60 днів. Щоб оновити: developers.facebook.com → застосунок Chesno Robota Poster → Сценарії використання → Access the Threads API → Settings → User Token Generator → Generate для cesnorobota, і вставте новий токен у той самий секрет.
- Додати пости: допишіть рядки в `posts_queue.csv` (status `queued`). Порожній `scheduled_at` можна заповнити командою `python autopost.py schedule`.
- Ручний запуск або перевірка: вкладка Actions → «Автопостинг Threads» → Run workflow (є прапорець dry_run).


Два інструменти на офіційному Threads API від Meta:

1. **`autopost.py`**: публікує пости з черги `posts_queue.csv` кілька разів на день за розкладом.
2. **`comment_assistant.py`**: шукає популярні треди про роботу й відгуки, ШІ (Claude) пише 2-3 варіанти коментаря українською, **ви схвалюєте**, і лише тоді скрипт публікує з обмеженням частоти.

## Що Threads API дозволяє, а що ні

| Можливість | Статус |
|---|---|
| Публікувати свої пости за розкладом | ✅ одразу, для власного акаунта (ви додаєте себе як тестувальника застосунку) |
| Довгі тексти | ✅ ліміт 500 символів на пост; довший текст скрипт публікує **ланцюжком** (продовження відповіддю на свій пост) |
| Пошук чужих постів за ключовими словами (`keyword_search`) | ⚠️ **лише після App Review** дозволу `threads_keyword_search`. До схвалення пошук повертає тільки ваші власні пости |
| Коментувати чужі пости через API | ⚠️ лише з `threads_keyword_search` (після App Review) |
| Сортування «популярне» | ✅ `search_type=TOP`; кількість лайків чужих постів API в пошуку не віддає |
| Повністю автоматичні коментарі без людини | ❌ свідомо не робимо: Meta вважає масові однотипні відповіді спамом і блокує акаунти |

**Поки App Review не пройдено**, коментарі працюють у ручному режимі: ви вставляєте текст посту (`add`), ШІ пише варіанти, ви вибираєте й копіюєте текст у застосунок Threads.

## 1. Встановлення

Потрібен Python 3.10+.

```bash
cd threads-automation
python -m venv .venv
# macOS/Linux:  source .venv/bin/activate
# Windows:      .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # Windows: copy .env.example .env
cp posts_queue.example.csv posts_queue.csv
```

## 2. Застосунок Meta і токен (один раз, ~15 хв)

1. Зайдіть на [developers.facebook.com/apps](https://developers.facebook.com/apps), натисніть **Create App** і виберіть сценарій **Access the Threads API**.
2. У розділі **Use cases → Access the Threads API → Customize**:
   - додайте дозволи `threads_basic`, `threads_content_publish`, `threads_manage_replies`, `threads_keyword_search`;
   - у **Settings** вкажіть **Redirect Callback URL**, наприклад `https://example.com/threads-callback` (сторінка може не існувати, нам потрібна лише адреса з кодом).
3. **App roles → Roles → Add People → Threads Tester**: додайте свій акаунт Threads.
4. У застосунку Threads (або на threads.net) відкрийте **Налаштування → Обліковий запис → Дозволи вебсайтів → Запрошення** і прийміть запрошення.
5. Скопіюйте **Threads App ID** і **Threads App Secret** (розділ App settings → Basic) у `.env`, а також `THREADS_REDIRECT_URI` (точно таку ж адресу, як у п. 2).
6. Запустіть:
   ```bash
   python auth_setup.py
   ```
   Відкрийте посилання, дозвольте доступ, скопіюйте адресу, на яку вас перекине (з `?code=...`), і вставте в консоль. Токен збережеться в `data/token.json`.

Токен діє 60 днів. Скрипти самі оновлюють його, коли лишається менше 10 днів, тож достатньо, щоб автопостинг запускався хоча б раз на тиждень.

**Для пошуку чужих постів:** у панелі застосунку подайте `threads_keyword_search` (і `threads_manage_replies`) на **App Review**. Meta просить опис використання й скрінкаст. Чесний опис: «Інструмент для одного бренд-акаунта: знаходить пости про роботу, пропонує чернетки коментарів, кожен коментар людина переглядає й схвалює вручну; ліміт 15 на день».

## 3. Автопостинг

Черга в `posts_queue.csv` (відкривається в Excel / Google Sheets, кодування UTF-8):

| колонка | що писати |
|---|---|
| `id` | будь-який номер |
| `scheduled_at` | `2026-11-27 09:00` за київським часом, або порожньо, і скрипт сам розставить |
| `text` | текст посту. Для ланцюжка розділіть частини рядком `---` |
| `status` | `queued` (решту колонок заповнює скрипт) |
| `topic_tag` | необов'язково: тема поста в Threads, наприклад `Відгуки про роботу` (до 50 символів, без `.` і `&`). Тема допомагає потрапити в стрічку теми |
| `self_reply` | необов'язково: ваша перша відповідь під власним постом. Виходить через 3-10 хв після поста (`SELF_REPLY_DELAY_MINUTES`) і запускає обговорення |

Інші колонки (наприклад `rubric`) скрипт не чіпає і зберігає. Готовий банк постів із темами й авторськими відповідями лежить у `chesno-robota/posts_queue.csv`: його можна просто скопіювати сюди як `posts_queue.csv`.

```bash
python autopost.py schedule --dry-run   # подивитись, які дати отримають пости без дати
python autopost.py schedule             # записати дати (слоти POST_SLOTS ± випадкові 15 хв)
python autopost.py run --dry-run        # що опублікується зараз, без публікації
python autopost.py run                  # опублікувати ОДИН пост, час якого настав
python autopost.py status               # черга + квота Meta
```

Запобіжники (налаштовуються в `.env`): не більше `MAX_POSTS_PER_DAY` на день, щонайменше `MIN_GAP_MINUTES` між постами, до 3 спроб при помилці.

### Запуск за розкладом

Варіант А, комп'ютер або сервер, що працює постійно: `python autopost.py loop` (перевіряє чергу щохвилини).

Кожен запуск `run` спершу публікує авторські відповіді, час яких настав, тому запускайте його щонайменше раз на 5 хв.

Варіант Б, cron (macOS/Linux): `crontab -e` і рядок
```
*/5 * * * * cd /шлях/до/threads-automation && .venv/bin/python autopost.py run >> data/autopost.log 2>&1
```

Варіант В, Windows: Планувальник завдань → Створити завдання → Тригер «щодня, повторювати кожні 5 хв» → Дія: програма `шлях\.venv\Scripts\python.exe`, аргументи `autopost.py run`, робоча папка `шлях\threads-automation`.

Щоб пости виходили, коли комп'ютер вимкнено, той самий cron можна поставити на дешевий VPS.

## 4. Асистент коментарів

Додайте в `.env` ключ `ANTHROPIC_API_KEY` (його створюють на [console.anthropic.com](https://console.anthropic.com)).

```bash
python comment_assistant.py find      # пошук за COMMENT_KEYWORDS, пости за останні SEARCH_DAYS днів
python comment_assistant.py add       # (ручний режим) вставити текст посту й посилання
python comment_assistant.py draft     # ШІ пише 2-3 варіанти або радить пропустити
python comment_assistant.py review    # ви вирішуєте: 1/2/3 = схвалити, e = свій текст, r = нові варіанти, s = пропустити
python comment_assistant.py send --dry-run
python comment_assistant.py send      # публікує схвалені
```

Правила для ШІ (у `SYSTEM_PROMPT` всередині `comment_assistant.py`):
- лише українська, до 280 символів;
- гумор і сарказм спрямовані на ситуацію та корпоративні кліше, а не на автора;
- якщо людині важко, ШІ пише підтримку;
- без політики, війни, релігії, образ, лайки, тем зовнішності чи здоров'я, без звинувачень конкретних компаній чи людей, без посилань і хештегів.

Додатково пости зі «стоп-словами» (`COMMENT_STOP_WORDS`: війна, мобілізація, політика, смерть тощо) відсіюються ще до ШІ.

Ліміти публікації: `MAX_COMMENTS_PER_HOUR=4`, `MAX_COMMENTS_PER_DAY=15`, випадкова пауза 4-10 хв між коментарями, не більше одного коментаря одному автору на день. Історія зберігається в `data/comments_log.csv`.

**Порада:** не піднімайте ліміти різко. Новий акаунт, що за день лишив 50 коментарів, Threads швидко обмежує. Краще 10-15 влучних коментарів під свіжими популярними постами, ніж сотня шаблонних.
